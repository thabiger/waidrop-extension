# Free Distribution and Donations

WAiDrop is free and open source under the Apache License, Version 2.0; see
[`LICENSE`](../LICENSE). There is no paid tier, checkout, license key, trial or
entitlement check. Every feature described in the README and store listing is
available without a purchase.

## Donation link

The popup contains one optional link:

- **Buy me a coffee** opens
  <https://buymeacoffee.com/tomaszhabiq> in a new tab.

Donations are voluntary and do not unlock anything. The extension does not send
archive data, Dropbox credentials or encryption keys to the donation page. Once
the link is opened, Buy Me a Coffee's own terms and privacy policy apply.

## Build and release

The packaged extension contains no ExtensionPay, Stripe or other payment
provider code. Package verification checks that only allowlisted runtime files
are shipped.
